 My First Website

Project Description:
This is a basic website created using HTML, CSS, and JavaScript. It demonstrates how these three technologies work together to create a simple and interactive webpage.

Technologies Used
- HTML: Used to create the structure of the webpage.
- CSS: Used to add colours, styling, and design.
- JavaScript: Used to add functionality and interactivity.

Project Files:

text
My-First-Website/
│
├──index.html
├── style.css
├── script.js
└── README.md


Features
- Simple webpage design.
- Light blue background.
- Heading displayed using HTML.
- Styled button using CSS.
- Alert message displayed using JavaScript when the button is clicked.

How to Run the Project

1. Download or clone the project.
2. Keep all files in the same folder.
3. Open `index.html` in any web browser.
4. Click the **Click Me** button.
5. A welcome message will appear.

 Working:
HTML creates the webpage structure, CSS provides the design, and JavaScript displays an alert message when the user clicks the button.
